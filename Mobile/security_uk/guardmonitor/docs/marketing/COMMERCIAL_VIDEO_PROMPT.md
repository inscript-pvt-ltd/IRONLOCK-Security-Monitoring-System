# IronLock — Guard Monitor · Commercial Video Prompt

**Format:** 20-second commercial · **Aesthetic:** clean, premium, Apple-style.
**Built for:** modern text-to-video tools (Veo 3 / Sora / Kling / Runway). Generate each shot,
then cut together in an editor; add the on-screen text + logo there (not in the AI).

---

## Aesthetic lock (keep identical across every shot)

- **Look:** minimal, premium, lots of negative space; deep navy→black gradient backgrounds with
  soft gold `#D4AF37` accents and crisp white UI. Soft studio lighting, glossy reflections, gentle
  depth of field.
- **Motion:** slow, smooth, deliberate — push-ins, subtle orbits, parallax float. No shake, no grit.
- **Feel:** quiet confidence. Technology as reassurance. *"Effortless. Trusted. Always watching over you."*
- **Brand:** IronLock — gold **phoenix** emblem · navy `#07111F` · gold `#D4AF37`.
- **Subject:** a calm, modern UK security guard in a clean, well-lit space (not gritty/night-horror).

### Master style line (prepend to any shot prompt)
```
Apple-style product commercial, ultra-clean and minimal, slow deliberate camera moves,
soft studio lighting, deep navy-to-black gradient backgrounds with crisp white UI and
subtle gold accents, glassy reflections, shallow depth of field, photoreal, pristine,
quiet and reassuring tone. No clutter, no text overlays, no grain.
```

---

## Tightened voiceover — 3-line Apple cadence (use for BOTH cuts)

> *(0–7s)* "Every shift begins alone."
> *(7–15s)* "Presence, proven — in real time."
> *(15–20s)* "IronLock. Lone, never alone."

*Delivery: calm, unhurried, long pauses. ~16 words total. Let the visuals breathe.*

## CUT A — 16:9 (web / landing hero / TV)

Six beats, ~3s each. Real-world + UI, resolving on the emblem.

**1 · 0–3s — Brand open**
```
Black-to-navy gradient void. A single gold phoenix emblem assembles from fine light
particles, glints, settles centered. Minimal, premium, soft reflection on a glossy
floor. Slow push-in.
```

**2 · 3–7s — Guard + live map**
```
Clean, softly-lit environment, a composed UK security guard walks calmly, holding a
phone. The phone's dark-navy app UI floats and enlarges out of the screen into 3D
space beside him: a live map, glowing geofence ring, pulsing GPS dot. Smooth parallax,
shallow focus, pristine.
```

**3 · 7–11s — Photo verification (macro)**
```
Extreme close-up of the phone screen, glossy glass with soft reflections. A "verify
presence" card appears with a thin gold countdown ring; a front-camera capture gently
illuminates the guard's face for a frame, a clean gold checkmark confirms. Satisfying
minimal UI animation, navy + white + gold.
```

**4 · 11–14s — Wakefulness check (macro)**
```
Macro of the UI: a 4-digit code floats forward in crisp white type; a thumb taps, each
digit lights gold, a checkmark pulses. Beautiful micro-interaction, soft depth, Apple-clean.
```

**5 · 14–17s — Supervisor dashboard**
```
Cut to a calm, bright control space: a large dashboard with a clean UK map, live guard
markers glowing gold on navy, tidy status panels. A supervisor watches, assured. Slow
lateral dolly, minimal, premium.
```

**6 · 17–20s — Logo resolve**
```
Everything dissolves to a clean navy frame. The gold phoenix emblem settles center with
a soft glow and reflection. Hold, serene, confident.
```

## Production notes (both cuts)

- **Music:** single sustained piano notes + soft airy pad, one gentle swell into the logo. No
  percussion, no tension (classic Apple restraint).
- **Audio mix:** VO forward and intimate; music low; subtle UI "tick/whoosh" on each gold checkmark.
- **Negative prompt:**
  `no grit, no rain, no darkness/horror, no clutter, no readable gibberish UI text, no real
  third-party logos, no distorted hands, no fast jittery cuts, no excessive lens flares, no grain`
- **Consistency:** lock one **seed** + an identical guard description across shots; keep the UI
  navy/gold identical in every macro; reuse the same phoenix emblem render for the open + close.
- **Exports:** master 16:9 (Cut A); 9:16 (Cut B); optional 1:1 center-crop from Cut B for feed ads.
